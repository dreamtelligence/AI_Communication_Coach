# Recruiter review and verification

Date: 10 November 2026. Scope: the public CoachVoice repository, the Fullstack/AI interview addition, and B2B copy on Dreamtelligence's service page. This describes the proposed source changes and a separate development environment; it is not a production release record.

## Result

The public demo catalogue now contains salary negotiation, customer complaint and a Fullstack/AI interview. The former dating scenario is retained internally and omitted from the public catalogue. The Dreamtelligence service page replaces its date example with the interview. No other dating references were found in that site's `app`, `components` or `data` source directories.

The README now uses a screenshot of the current B2B interview selection, accurately describes the stack and limits, and links to the research and the reproducible provider evaluation. There is no claimed open-source license or green CI badge.

The cases deliberately check that a technical error does not become a presumed motivation problem or an automatic communication failure. The five fixtures are a regression sample, not evidence that all interviews will be scored correctly.

## Dependency change

The unused `shadcn` command-line package was installed as an application dependency. Source, configuration and scripts did not import or invoke it. Removing it removed its CLI/server dependency tree; existing checked-in UI components remain in use. Compatible package updates address the remaining audit findings. React stays on version 18. The committed lockfile and `npm ci` reproduce the installation. CI now also invokes the existing npm audit script.

## Open items before presenting the new live scenario

1. **GitHub Actions is externally blocked.** The existing [Checks run](https://github.com/dreamtelligence/AI_Communication_Coach/actions/runs/42781183541) has no executed test steps. GitHub's annotation says the account is locked due to a billing issue. Account billing must be resolved and CI rerun; local success must not be described as a successful GitHub run.
2. **Human live interview acceptance remains open.** A person should check question order, natural follow-ups, thinking pauses, own questions, avatar hang-up, transcript delivery and final grading using microphone/video. The implemented prompts and successful text regression do not prove natural live delivery.
3. **Demo operating limits remain.** Public sessions consume provider resources. Existing per-IP and global in-memory limits remain; they are not accounts, a durable quota system or a hard monthly spending cap. Interview feedback is not a hiring decision or a verified assessment of professional competence.
4. **Deployment is separate.** The development backend and local frontend verify the proposed change. Publishing the Coach frontend/backend and the service-page copy must be coordinated so the public page advertises a scenario that the public backend actually offers.

The site's unrelated Supabase setup, a new account system, CV uploads, additional interview professions and a project-wide license were outside this change.
